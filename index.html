📖 Schritt-für-Schritt – So startest du dein Live-Quiz

  1. Host öffnen: Klicke auf „Zur Host-Seite“ (auf einem großen Bildschirm).
  2. Session erstellen: Gib einen Namen ein und klicke „Neue Session“. QR-Code erscheint.
  3. Excel laden: Lade deine Fragen-Datei hoch (Beispieldatei siehe unten).
  4. Spieler einladen: Spieler scannen QR-Code, geben Namen ein und warten.
  5. Quiz starten: Mit „Nächste Frage“ wird die aktuelle Frage angezeigt.
  6. Antworten sammeln: Spieler antworten auf Smartphone – Host sieht Antworten in Echtzeit.
  7. Auswerten: Host klickt „Auswerten & Punkte vergeben“ – System berechnet Punkte.
  8. Nächste Frage bis alle Fragen gespielt sind.

💡 Beispiel-Excel-Struktur: Spalten: Frage, Typ, Antwort, Optionen, Bild-URL, Zeit (Sek.), Punktregel, Reihenfolge wichtig
