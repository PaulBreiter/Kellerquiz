📖 So startest du

  1. Host öffnen (oben links) – am besten auf Laptop/Tablet.
  2. Session erstellen → QR-Code erscheint.
  3. Excel-Datei hochladen (Spalten: Frage, Typ, Antwort, Optionen, Bild-URL, Zeit, Punktregel, Reihenfolge).
  4. Spieler scannen QR-Code, geben Namen ein.
  5. Host klickt „Nächste Frage“ – Spieler sehen Frage und antworten.
  6. Host klickt „Auswerten“ – Punkte werden automatisch vergeben.
  7. Nach jeder Runde „Nächste Frage“ bis alle Fragen gespielt sind.
