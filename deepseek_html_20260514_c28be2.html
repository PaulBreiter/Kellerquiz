📖 Schritt-für-Schritt – So startest du dein Live-Quiz

  1. Host öffnen: Klicke auf „Zur Host-Seite“ (oben). Am besten auf einem großen Bildschirm / Laptop.
  2. Session erstellen: Gib einen Namen ein und klicke „Neue Session“. Es wird ein QR-Code generiert.
  3. Excel laden: Lade deine Fragen-Datei hoch (Vorlage siehe unten). Die Fragen werden in der Datenbank gespeichert.
  4. Spieler einladen: Die Spieler scannen den QR-Code oder rufen den Link auf, geben ihren Namen ein und warten auf die erste Frage.
  5. Quiz starten: Der Host sieht alle Spieler. Mit „Nächste Frage“ wird die aktuelle Frage angezeigt.
  6. Antworten sammeln: Spieler geben ihre Antworten auf dem Smartphone ein. Der Host sieht alle Antworten in Echtzeit.
  7. Auswerten: Der Host klickt „Auswerten & Punkte vergeben“ – das System berechnet die Punkte automatisch (je nach Fragetyp).
  8. Manuelle Anpassung: Falls nötig, können Punkte nachträglich angepasst werden.
  9. Nächste Frage: Nach der Auswertung geht es zur nächsten Frage – bis alle Fragen gespielt sind.

💡 Tipp: Eine Beispieldatei mit allen Fragetypen findest du in der Host-Seite (dort gibt es einen Download-Link).
